# MoTech Audit — Premium Visual Redesign

GitHub Pages-ready static website package. The HTML pages and `assets/` directory are at the package root.

See **部署指南-中文.md** for backup, deployment, verification, and rollback instructions.

Pages: `index.html`, `services.html`, `process.html`, `scanner.html`, `reports.html`, `insights.html`, `about.html`, `contact.html`.

Third-party market data and token screening rely on external APIs/network/CORS availability. The contact form opens an email draft; it does not store submissions on a server.
